# Shape Area Calculator - AWT

A simple **Java AWT GUI project** that calculates the area of different geometric shapes.

## ✨ Features

* Select a geometric shape
* Enter the required measurements
* Calculate the area
* Displays the calculated result
* Uses separate frames for different shapes

## 🛠️ Technologies Used

* Java
* AWT (Abstract Window Toolkit)

## 📐 Shapes

Currently supports:

* Circle
* Rectangle
* Square
* Triangle

*More shapes may be added in the future.*

## ▶️ How to Run

1. Clone the repository.
2. Open the project in your Java IDE.
3. Run the main Java file.
4. Select a shape and enter the required measurements.

## 🎯 Purpose

This project was created to practice **Java AWT, GUI components, event handling, frames, buttons, and basic mathematical operations**.
