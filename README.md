# Shape Area Calculator - AWT

A simple **Java AWT GUI project** that calculates the area of different geometric shapes.

## ✨ Features

* Select a geometric shape
* Enter the required measurements
* Calculate the area
* Clear input and results
* Input validation and error handling
* Displays meaningful error messages
* Uses separate frames for different shapes

## 🛠️ Technologies Used

* Java
* AWT (Abstract Window Toolkit)
* ActionListener

## ⚠️ Input Validation

The calculator handles:

* Empty input fields
* String/alphabetic input
* Zero values
* Negative values
* Invalid numerical input

## ▶️ How to Run

1. Clone the repository.
2. Open the project in your Java IDE.
3. Run the main Java file.
4. Select a shape and enter the required measurements.

## 🎯 Purpose

This project was created to practice **Java AWT, GUI components, event handling, frames, buttons, input validation, error handling, and basic mathematical operations**.
